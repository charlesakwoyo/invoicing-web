# QuickPay – Invoicing Website

The marketing website for **QuickPay**, an invoicing product, built with Next.js and TypeScript. It pairs with the [QuickPay Invoicing Dashboard](https://github.com/charlesakwoyo/invoicepro).

## Features

- Landing page with hero section, feature highlights and pricing plans.
- Responsive navigation bar and footer.
- Built with the Next.js App Router, using a route group for the marketing pages.

## Tech stack

Next.js (App Router) · React · TypeScript · Tailwind CSS · ESLint

## Getting started

```bash
git clone https://github.com/charlesakwoyo/invoicing-web.git
cd invoicing-web
npm install
npm run dev
```

Open `http://localhost:3000`.
